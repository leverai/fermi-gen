Implement the following feature:

## Feature
- Create pre-defined sound profiles to use in the live typing text widget.

## Background
- In the last commit a new Live Typing Text (LTT) widget was added which allowed the @beautifulMentionto render the text as it's being typed live with sounds.
- The LTT widget accepts a sound profile argument. When null (default), no sound is played. When it's a string, the code looks for a folder with the same name under `assets/sounds/ltt/` and uses its sounds in a sound pool to play while typing.
- See @beautifulMentionfor more info.
- This feature was added to allow users to purchase sound profiles with in-game currency. To do so, we must have pre-defined sound profiles
