## Features
A. Add a ranking system (backend and frontend).

## Background
- The ranking system should be based on the player's average percentile:
  ```
  | Tier | Criteria | Title |
  | :--- | :--- | :--- |
  | Tier 1 | Bottom 40% | Observer |
  | Tier 2 | Top 60% | Guesstimator |
  | Tier 3 | Top 25% | Analyst |
  | Tier 4 | Top 10% | Strategist |
  | Tier 5 | Top 2% | Fermi Master |
  ```
- The backend already computes and returns the average percentile as part of user stats.
  - See `apps/fermi-api/app/api/v1/endpoints/game.py#L186-196`
- The frontend simply shows the percentile as a percentage in the stats card of the me tab in the main screen:
  - Stats card: `apps/fermi-frontend/lib/widgets/stats_card.dart`
  - me tab: `apps/fermi-frontend/lib/screens/main/widgets/me_tab.dart`
  - main screen: `apps/fermi-frontend/lib/screens/main/main_screen.dart`
- Backend must return a rank object instead of returning the percentile alone.
  - The rank object contains the percentile, id, name, and image url of that rank (similar to existing patterns, e.g. for difficulties in the /game/config endpoint).
  - The frontend should display the rank name and image in the stats card.
- The following assets are available for ranks:
  - `apps/fermi-api/static/ranks/<1 through 5>.svg`

## Additional Requirements
- When displaying the rank in the stats card, the image should be small and displayed above the rank name.
- Replace the position of the Level and Rank in the stats card. Rank should be last.
- Update backend and frontend docs as needed.
